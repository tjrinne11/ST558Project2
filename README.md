# North Carolina Census Data App

An interactive Shiny app to explore North Carolina Census data

## Purpose
This app lets users filter NC demographic data, view and download subsets, and create graphs and summary tables

## Features
* **About:** Background on the Census data and instructions for using the app
* **Data Download:** Interactive table to explore and download the filtered data as a CSV
* **Data Exploration:** Numerical summaries and plots across variables.
